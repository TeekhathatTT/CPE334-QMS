| F-08 | No-show handling and recovery | An assigned operator marks a `CALLED` entry `NO_SHOW` (`noShowAt`, `noShowCount`); the operator may return it to the queue once at its original FIFO position (`recoveredAt`); a second no-show is final. `NO_SHOW` is not active, so the customer may also rejoin. Issue #41. Issue #42. Design: [features/sprint-2-f09-multi-counter.md](./features/sprint-2-f09-multi-counter.md). **Status: Released and deployed (2026-11-28, release `096ab1f` via PR #71, Cloud Run revision `qms-00007-vf8`; see [sprints/sprint-2/completion.md](./sprints/sprint-2/completion.md)).** | OPERATOR, CUSTOMER, system | 2 | FR-17–FR-19 (new); BR-18–BR-20 (new, rev. 4.1); BR-10, BR-16 (notes in SRS v4.0); FR-03, FR-07–FR-13, FR-16, BR-01, BR-07, BR-11, BR-12 (affected, unchanged); NFR-02–NFR-08; AC-35–AC-44 | Depends on F-03, F-05; interacts with F-04, F-07, F-08 |
| F-10 | Priority queue policy | Two-level `QueuePriority` (`NORMAL` default, `PRIORITY`) managed by assigned operators on `WAITING` entries via `PATCH /api/operator/queue-entries/{entryId}/priority`; server-enforced rejection of customer self-elevation on join (`403 FORBIDDEN` before DB lookups); priority-aware FIFO ordering (`PRIORITY` before `NORMAL`, then `joinedAt ASC, id ASC`) across F-09 counter Call Next, legacy Call Next, `aheadCount`, and `WAITING`-only operator list sorting; preserves `priority` on F-08 `NO_SHOW` recovery; manual anti-starvation policy in Sprint 2. Design: [features/sprint-3-f11-operational-analytics.md](./features/sprint-3-f11-operational-analytics.md). **Status: Specified (contract v1.0, 2026-11-28, pending review by `@Khwanklao`); not implemented.** | OPERATOR, management | 3 | FR-23, FR-24; BR-24–BR-26; FR-13, BR-11 (data source, unchanged); NFR-02, NFR-04, NFR-06, NFR-08; AC-56–AC-62 | Depends on F-01, F-05; reads F-07–F-10 data |
| F-12 | Advance appointment booking | Operators publish slots (time, duration, capacity) for assigned queues. Design: [features/sprint-3-f12-appointment-booking.md](./features/sprint-3-f12-appointment-booking.md). **Status: Specified (contract v1.0, 2026-11-28, pending review by `@Khwanklao`); not implemented (due 13 December).** | CUSTOMER, OPERATOR | 3 | FR-25–FR-30; BR-27–BR-32; BR-21 (rev. 6.0 note); BR-05, BR-06, BR-08 (applied at check-in); NFR-02–NFR-06, NFR-08; AC-63–AC-72 | Depends on F-03, F-04; interacts with F-07, F-08, F-10, F-11 |

Issue #44 (contract). Design: [features/sprint-3-f13-product-hardening.md](./features/sprint-3-f13-product-hardening.md). **Status: Specified (contract v1.0, 2026-11-28, pending review by `@Khwanklao`); not implemented (due 13 December).** | System / delivery team | 3 | FR-31, FR-32; BR-33; NFR-09–NFR-13 (new); NFR-01–NFR-08 (re-verified); AC-73–AC-82 | Depends on F-01–F-12 |
